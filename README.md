# Welle's Warfare

A browser first-person shooter by 2NINES: nine characters (including Mizzy the dog), six maps,
Mizuno golf clubs, throwable Diet Cokes, and online free-for-all with match codes (no sign-in).

**Play:** https://grahamfish.github.io/welleswarfare/

Online play: both players pick **Online**, type the same match code, and deploy on the same map.
